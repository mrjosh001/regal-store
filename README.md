# Regal Store

Premium product catalog / e-commerce website inspired by QAFRICA.

Built with:
- **Next.js** (React framework)
- **Supabase** (Database, Auth, Storage)
- **Vercel** (Hosting)
- **Tailwind CSS** + Shopify-inspired DESIGN.md for beautiful consistent UI
